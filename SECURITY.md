# Security Policy

## Supported Versions

Only the latest Packly Developer Preview Homebrew formula is supported.

## Reporting A Vulnerability

Do not open a public issue for secrets, arbitrary file write, command execution,
release asset integrity, signing, updater, or credential exposure findings.

Use GitHub private vulnerability reporting for the Developer Preview repository:

```text
https://github.com/Orvek-dev/packly-developer-preview/security/advisories/new
```

If private reporting is unavailable, open a minimal public issue titled
`[security-contact]` without exploit details, secrets, source code, private Pack
contents, or full local paths. A maintainer will move the discussion to a
private channel.
